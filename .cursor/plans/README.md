# Plans Directory

Save implementation and migration plans here with date prefix.

Example filename: `2026-09-02-blog-migration-plan.md`

Plans must include:
1. Goal
2. Current state
3. Relevant files
4. Proposed changes
5. Risks
6. Verification
7. Rollback
8. Definition of done

Current phase: Planning only. No development plans should be executed until audit is complete.
