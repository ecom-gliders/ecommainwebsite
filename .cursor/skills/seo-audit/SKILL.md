# SEO Audit Skill

## Per-page audit template

For each URL, create or update a record in `docs/seo/SITE-SEO-MAP.md`.

```
PAGE:
URL and page name

PURPOSE:
Primary business purpose

AUDIENCE:
Target audience

SEARCH INTENT:
Informational / Commercial / Transactional / Navigational

PRIMARY KEYWORD:
...

SECONDARY KEYWORDS:
...

ENTITY:
Company, service, location entities

SEO:
Title, meta, H1, headings, canonical, indexability, schema, internal links

AEO:
Direct answer opportunities, FAQ candidates

GEO:
Entity clarity, consistent service descriptions

LLM SEO:
Machine-readable summaries, explicit terminology

CONTENT:
Gaps, weak proof, unclear language

INTERNAL LINKING:
Required links to and from this page

SCHEMA:
Required structured data types

PERFORMANCE:
Core Web Vitals issues

UX:
Friction points

COMPETITIVE GAP:
What competitors do better

RECOMMENDATION:
Prioritized actions

VERIFICATION:
How success will be measured
```

## Blog posts (migration priority)

For each blog post verify and record:
- Current URL path (must be preserved)
- Current title and meta description
- Current ranking keywords if known
- Internal links pointing to this post
- External backlinks if known
- Featured image URL
- Publish and modified dates

## Competitive research

Record in `docs/seo/COMPETITIVE-RESEARCH.md`:
- Competitor name and URL
- Target keyword
- Their ranking approach
- Content gap we can fill
- Differentiation opportunity

Do not copy competitor wording.

## Rules

No keyword stuffing. Write for humans first.
Preserve existing rankings during migration. URL path changes require explicit approval.
