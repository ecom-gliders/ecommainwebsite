## Current phase

Planning and audit only. Development has not started.

## Quick start for AI agents

1. Read `AGENTS.md`
2. Read `.cursor/rules/00-project-core.mdc`
3. Read `obsidian/01-Project/Project-Brief.md`
4. Check `docs/ai/SESSION-STATE.md` for current work state
5. Follow rules in `.cursor/rules/` for the task at hand
