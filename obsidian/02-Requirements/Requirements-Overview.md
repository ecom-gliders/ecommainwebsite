# Requirements Overview

Status: Draft.

## Functional requirements

1. Rebuild ecomgliders.com on custom code
2. Preserve all blog URL paths exactly
3. Migrate all blog content with metadata intact
4. Migrate all service pages
5. Migrate case studies and testimonials
6. Preserve contact form functionality
7. Preserve free audit form
8. Maintain navigation structure (can improve UX)

## Non-functional requirements

1. Performance equal to or better than current site
2. Mobile responsive
3. WCAG AA accessibility minimum
4. SEO preserved or improved (never degraded without approval)
5. Professional copy throughout
6. Secure forms and admin access

## Out of scope (current phase)

- Development
- Tech stack selection
- Design redesign (audit first, then decide)
