# SEO Architecture

## Scope

Every indexable page on ecomgliders.com requires a complete SEO record.

## Record location

Per-page records in `docs/seo/SITE-SEO-MAP.md`
Detailed audits in `obsidian/08-SEO/`

## Required fields per page

- URL path
- Page purpose
- Target audience
- Search intent
- Primary keyword
- Secondary keywords
- Title tag
- Meta description
- H1
- Heading hierarchy
- Internal links (in and out)
- Canonical URL
- Indexability (index/noindex)
- Sitemap inclusion
- Structured data type
- Image alt texts
- Page speed notes

## Optimization layers

| Layer | Focus |
|-------|-------|
| SEO | Traditional search ranking factors |
| AEO | Answer engine extractability |
| GEO | Generative engine entity clarity |
| AI SEO | Machine-readable content structure |
| LLM SEO | Explicit terminology and summaries |
| Technical SEO | Crawlability, speed, mobile, schema |
| On-page | Content, headings, meta, links |
| Off-page | Backlinks, citations, directories |
