# Decision Record Template

Copy this template for each architecture or project decision.

```
Date: YYYY-MM-DD

Decision:
What was decided?

Context:
What problem required the decision?

Options:
A: ...
B: ...
C: ...

Chosen:
Selected option.

Why:
Evidence and rationale.

Tradeoffs:
What becomes harder?

Dependencies:
What depends on this decision?

Impact:
What needs updating?

Verification:
How will we know it remains correct?
```
